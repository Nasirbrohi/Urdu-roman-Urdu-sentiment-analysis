# Urdu and Roman Urdu Sentiment Analysis

Final Year Project for Sentiment Analysis of Urdu and Roman Urdu Social Media Text.

## Project Overview

This project develops a machine learning based sentiment analysis system for Urdu and Roman Urdu social media text.

The system classifies text into two sentiment classes:

- Positive
- Negative

## Languages

- Urdu
- Roman Urdu

## Machine Learning Models

Three machine learning models were implemented:

1. Logistic Regression
2. Multinomial Naive Bayes
3. Linear SVC

## Text Representation

TF-IDF (Term Frequency-Inverse Document Frequency) was used to convert text into numerical features.

## Application

A Streamlit web application was developed for:

- Single text sentiment prediction
- Urdu and Roman Urdu selection
- Machine learning model selection
- Confidence score display
- Batch CSV analysis
- Sentiment analytics
- Results visualization
